D'ANGELO DISPATCH - STATIC VERSION

1. Run supabase/schema.sql in Supabase SQL Editor.
2. In config.js paste:
   - Supabase Project URL (ends in .supabase.co)
   - Supabase publishable key or legacy anon key
3. Upload all files to a new GitHub repository.
4. Import that repository into Vercel and click Deploy.
5. No Vercel environment variables are needed.
6. Open the site, click Create first account, and use brandon@dangelo-brothers.com.

This version uses plain HTML/CSS/JavaScript, so there is no build step and no npm dependency failure.
